# Design Corpus

This directory contains design authority and design history for `vibechord`.

## What Lives Here

- `VISION.md` — product and behavioral design authority.
- `SDLC.md` — project process, review, and artifact lifecycle.
- `TESTING-RAILS.md` — verification architecture and testability gates.
- `VERIFICATION-SCENARIOS.md` — concrete verification scenario catalog.
- `MOVING-PARTS.md` — minimum planned core moving parts and extension rules.
- `ARCHITECTURE.md` — implementation architecture authority.
- `CLI-VISION.md`, `TUI-VISION.md`, `REST-API-VISION.md` — delivery surface visions.
- `adr/` — architectural decisions.
- `plans/` — implementation plans.
- `brainstorm/` — design exploration.
- `internal/` — critiques, red-team notes, and working design artifacts.

## What Does Not Live Here

This directory is not the primary end-user documentation surface. Public docs
belong in [`../docs/`](../docs).
